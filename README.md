
# Tulas International School — Homepage Redesign

A modern, responsive, animated homepage redesign for Tulas International School, Dehradun.

## Live Website

https://tulas-school-redesign-ashy.vercel.app/

## Technologies Used

- React.js
- Vite
- Tailwind CSS
- Motion for React
- Lucide React

## Features

- Responsive navigation with mobile menu
- Animated hero section
- Scroll-triggered reveal animations
- Custom animated cursor
- Scroll progress indicator
- Academics and campus life sections
- Admissions call-to-action
- Responsive footer

## Run Locally

1. Clone the repository.
2. Install dependencies:

   npm install

3. Start the development server:

   npm run dev

4. Create a production build:

   npm run build

## Deployment

Deployed using Vercel with automatic deployments from GitHub.

## Disclaimer

This project is a frontend redesign created as part of a developer assessment. It is not the official website of Tulas International School.
